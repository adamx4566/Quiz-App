# Quiz-App

A simple Quiz Application built with HTML, CSS, and JavaScript.  
It allows users to answer multiple-choice questions and shows the final score at the end.

## Features
- Multiple-choice questions
- Displays one question at a time
- Tracks score
- Shows results at the end
- Restart quiz option
- Responsive and clean design

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
